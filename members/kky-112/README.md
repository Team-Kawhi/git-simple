\## 实验简答题

问题1：简述 Git 和 GitHub 的区别

答：Git 是分布式版本控制软件，运行在本地电脑，用来记录文件修改、管理版本、创建分支，不需要联网也能工作。

GitHub 是基于Git的远程代码托管网站（平台），用来存放远程仓库，方便多人协同、代码共享、提交审核（PR）。简单来说：Git是工具，GitHub是存放代码的线上平台。



问题2：什么是分支（branch），分支的作用是什么？

答：分支相当于代码的一条独立开发线路。在不改动主分支(main)代码的前提下，可以新建分支在上面做修改、写代码。

作用：多人并行开发互不干扰；新功能/实验在独立分支测试，不会破坏主分支稳定；开发完成后通过PR合并到主分支，出现问题可以随时切换回旧版本。



问题3：简述 git add、git commit、git push 三条命令各自作用

答：

1\. git add：将本地修改的文件添加到暂存区，标记哪些文件准备提交。

2\. git commit：把暂存区的改动提交到本地仓库，生成版本快照，只保存在你电脑本地，需要写提交说明。

3\. git push：将本地仓库已经commit的版本，上传推送到GitHub远程仓库，让组长和其他组员看到你的代码。



问题4：什么是 Pull Request（PR），它的作用？

答：Pull Request 是向仓库维护者（组长）发起的代码合并申请。

作用：组员把自己分支的修改提交给组长；组长可以在线查看、审阅代码，讨论修改内容，确认无误后合并到主分支；方便代码审核、团队协作，保证主分支代码安全。
